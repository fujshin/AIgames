# えいたんクエスト（英単語RPG） v1.1.4.1

中1〜高3の 学年別 英単語を、RPGの バトルで おぼえる ゲームです。
サーバー不要。GitHub Pages に そのまま 置くだけで 動きます（セーブは ブラウザの localStorage）。

現在あそべるのは **中1（745語・8章）** です。中2〜高3は「準備中」と表示されます。

## 公開のしかた（GitHub Pages）
1. このフォルダの中身を リポジトリの ルートに アップロード（`index.html` が いちばん上）
2. **Settings → Pages → Branch: main / (root)** で Save
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で 遊べます

## 更新するときの キャッシュ対策
`index.html` の `app-version` と `?v=`、`js/game.js` の `APP_VERSION` を 同じ番号に 上げてください。
開いたときに 新しい版を 自動で 確認して 読み直します。

## ファイル構成
```
index.html           画面の骨組み
css/style.css        見た目
js/config.js         学年・地方・モンスターの設定
js/words_j1.js       中1の単語データ（745語）
js/game.js           ゲーム本体
assets/              イラスト（なくても 絵文字で 動きます）
.nojekyll            GitHub Pages 用の 空ファイル
```

## 学年を ふやすとき
1. `js/words_j2.js` を `WORDS.j2 = [ ... ];` の形で 作る（中身の形式は words_j1.js と同じ）
2. `index.html` に `<script src="js/words_j2.js?v=..."></script>` を 1行 追加
→ 中2の タブが 自動で 遊べるように なります（100語ごとに 1章、10語ごとに 1ステージ）

単語データの1行：`["英単語", "品詞(n/v/a/d)", "意味（／で併記）", "型", "例文（[ ]が空欄）", "例文の訳"]`

## 学習のしくみ
- **予習カード**：はじめての単語は 意味・型・例文を 確認してから バトルへ
- **出題形式**：英→日 / 日→英 / リスニング / 例文の空所（4択）/ つづり並べ / 例文の空所（入力）。ステージが進むほど 思い出す形式が ふえます
- **こたえたあとに 例文を表示**：正解なら 自動で次へ、まちがいは 読んでから 次へ
- **まちがえた単語は その戦いの中で もう一度** 出ます
- **間隔反復**：正解するたびに 1→2→4→7→14→30日後に「おさらいの塔」で 再出題
- **章ボス**：その章の 苦手な単語を 優先して 15問
- **れんぞく記録**：7日ごとに「おやすみ札」（1日 休んでも 記録が 切れない）

## イラストの差し替え（任意）
- 主人公・モンスター：背景透過 PNG、512×512（`assets/hero.png`, `assets/monsters/j1_1.png` など）
- 背景：JPG、1024×576（`assets/bg/j1.jpg` など）
ファイル名は `js/config.js` の id と 同じです。
