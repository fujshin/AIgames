# Rocket Lab（ロケット ラボ） v0.6

5さい向け。ブロックをつんでロケットを作り、とばして高さをくらべる。文字は使わず、絵と声で遊ぶ。

## 開き方
index.html をブラウザで開く（サーバー不要）。GitHub Pages にフォルダごと置いても動く。
タイトル画面：黄色（ぼうし）＝れんしゅう（チュートリアル）、赤（▶）＝じゆうに あそぶ。

## ファイル
| ファイル | 役割 |
|---|---|
| js/config.js | **調整する数値はここだけ**（重さ・力・くうき・高さの目印）。イベントのしくみ（RL.on / RL.emit） |
| js/icons.js | ボタンのアイコン（SVG） |
| js/parts.js | 部品の絵（SVG）と、つながり・はねの向き・はねがどこにつくか |
| js/physics.js | 飛び方の計算（時間を少しずつ進める） |
| js/audio.js | 効果音と声（声は順番に話し、話しおわりを知らせる） |
| js/builder.js | くみたて画面（使える部品の制限、マスの光り、変更のイベント） |
| js/flight.js | はっしゃの演出（メーター、ブースターの切りはなし、くうきの点線） |
| js/tutorial.js | チュートリアル（ステップの表 STEPS を書きかえれば内容を変えられる） |
| js/main.js | タイトル・じゆうモード・はっしゃ・けっか |
| tools/ | バランス確認（Node で実行） |
| assets/ | 画像生成の飾りを置く予定 |

## 物理のきまり（v0.6）
- 燃料がへると軽くなり、加速がどんどん大きくなる
- ブースター：縦につながった1本ごと。本数＝力、長さ＝燃える時間（1段 約2秒）。燃えつきた順に、**ついている はね ごと** 切りはなし
- くうき：高さ ATMO_H（300＝🌌）まで だんだん うすくなる
  - くうきの中だけ：空気のじゃま、はねがないと ぐらぐらが ふえる
  - くうきの外：じゃまも ぐらぐらの変化もない。はねは ただの おもり（はね1枚 0.15）
- 時間：全体を TIME_STRETCH 倍ゆっくり。再生は実時間（MAX_SEC をこえるときだけ早送り）

## チュートリアルの流れ
1. そうさ：えらぶ → おく → けす → つむ
2. ぶひん：まどだけ（とばない）→ エンジン → ねんりょう → はね → さきっぽ
3. ねんりょうを ふやす：3こ（でだしが ゆっくり・だんだん速く）→ 6こ → 7こ（おもすぎて とばない）
4. エンジンを ふやす：2こで おもいロケットも もちあがる
5. ブースター：かってに はずれる＝だんの ひみつ → はねを ブースターにつけて うちゅうの てまえで すてる

## バランスの確かめ方（必ず両方やる）
1. `node tools/balance_check.js`：代表的な構成と、左右対称な構成の総当たり（結果例：tools/balance_v0.6.txt）
2. `PROGRESS=1 FAST=1 node tools/search_max.js 20`：変な積み方も含めて最大を探す。何本か別々に実行し、最後の値は細かい刻みで再計算される
   - v0.6の結果：対称の最大 約7,300、探索の最大 約8,100。土星（12,000）まで約1.5倍の余裕
