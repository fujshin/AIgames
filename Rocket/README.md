# Rocket Lab（ロケット ラボ） v0.11.1
5さい向け。ブロックをつんでロケットを作り、とばして高さをくらべる。文字は使わず、絵と声で遊ぶ。
## 開き方
index.html をブラウザで開く（サーバー不要）。GitHub Pages では `Rocket/` フォルダに置く。
タイトル画面：黄色（ぼうし）＝れんしゅう（チュートリアル）、赤（▶）＝じゆうに あそぶ（たかさ）、青（地球）＝うちゅうモード【v0.8】。

## バランス（v0.7）
- 1段（リングなし）の最大：左右対称の総当たり 9,065、変な積み方の探索 約9,400 → 土星に届かない
- 2段：「地上用 → 宇宙用」でだけ 土星に届く（例：地上用＋燃料3｜宇宙用＋燃料1、ブースター5段＋はね外 = 12,133）
- 「宇宙用 → 地上用」（逆）は 1段目が うごけない
### 確かめ方（数値を変えたら必ず両方）
1. `FAST=1 node tools/balance_check.js`：代表構成と 左右対称の総当たり（1段・2段）。結果例 tools/balance_v0.7.txt
2. `PROGRESS=1 FAST=1 NORING=1 node tools/search_max.js 3`：リングなしで 変な積み方も含めた最大（何本か並行で）
## v0.6.3 からの変化
- 縦 7 → 9 マス
- ブースターは胴体の となりで、胴体の高さまで（はみ出した分は 半とうめいになり、ロケットに ふくまれない）。そのため「短い胴体＋長いブースター」の高さは v0.6.3 より低くなる。それ以外の構成は v0.6.3 と同じ高さ
