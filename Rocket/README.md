# Rocket Lab（ロケット ラボ）

5さい向け。ブロックをつんでロケットを作り、とばして高さをくらべる。

## ファイル
| ファイル | 役割 |
|---|---|
| index.html | 画面のわく。scriptの読み込み順に意味がある |
| css/style.css | 見た目 |
| js/config.js | **調整する数値はここだけ**（重さ・力・高さの目印） |
| js/icons.js | ボタンのアイコン（SVG） |
| js/parts.js | 部品の絵（SVG）と、つながり・はねの向きの判定 |
| js/physics.js（v0.4: ブースター） | 飛び方の計算。0.02秒ずつ時間を進める（燃料が減ると軽くなり加速が増す） |
| js/audio.js | 効果音と声 |
| js/builder.js | くみたて画面 |
| js/flight.js | はっしゃの演出 |
| js/main.js | つなぎこみ |
| assets/ | v0.3で画像生成の飾りを置く |

## 開き方
index.html をブラウザで開く（サーバー不要）。GitHub Pages にフォルダごと置いても動く。

## ひみつ
右下の版表示を3回タップすると見本のロケットが組み上がる。

## バランスの確認
`node tools/balance_check.js` で代表的な構成の高さ・出だしの加速・燃焼時間を一覧できる（結果例：tools/balance_v0.5.txt）。数値は js/config.js の PHYS を変える。

## v0.4で追加
- 固体ロケットブースター：胴体の横に縦に置く。力が強く約1.6秒で燃えつき、勝手に切りはなされて落ちる（2段式の予告）
- スピードメーター（針＋デジタル数字）、高さの数字、飛行時間の時計。結果画面に高さと最高速
- 再生：最初の3秒は実時間（出だしと切りはなしを見せる）、その後は早送り

## v0.5で変えたこと
- 再生は実時間（早送りしない）。さらに TIME_STRETCH=1.3 で全体を1.3倍ゆっくりに（高さは変わらない）
- ブースターは「縦につながった1本」ごとに計算：本数＝力、長さ＝燃える時間（1段約2秒）。燃えつきた順に1本ずつ切りはなし
- ついているブースターも空気のじゃまになる。はねはブースターの横にもつく
- 高さの目印に ☄️（760）を追加。土星（950）は1段＋ブースターでは届かない

## バランスの確かめ方（必ず両方やる）
1. `node tools/balance_check.js`：代表的な構成と、左右対称な構成の総当たり
2. `PROGRESS=1 node tools/search_max.js 50`：左右非対称・変な積み方も含めて最大の高さを探す（何回か、別々に実行する）
   - v0.5の結果：対称の最大 841、探索の最大 842（どちらも ☄️。土星950まで余裕約110）
