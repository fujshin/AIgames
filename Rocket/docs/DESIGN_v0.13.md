# Rocket Lab v0.13：月往還（実装の 記録）

v0.12 の 上に 足した。設計の「決めて ほしい こと」は すべて 案の とおり（18行／✂️ は 2回 おし／月からは 自動で 離陸／熱は 演出だけ／最大G は 数字だけ／月面は 自動で おわらない）。

## 1. ながれ
打ち上げ → 月に 着陸 →【月面】🚩・✂️・🔥・🏁 → 🔥 で 自動 離陸（月を まわる ところで 自動で とまる）
→ 前へ ふかして「かえれる 線」（🏠）が 出たら とめる → 地球へ → くうきで 🔥 → 🪂 → 着陸 ⭐5・🪨

## 2. 物理（js/physics2d.js）
| しくみ | 中身 |
|---|---|
| 月面で まつ | 月に 着陸して、いまの 段から 上に 液体エンジン＋燃料が あれば おわらない（`sim.surface`）。まつ 間は 時間が とまる。燃料が なければ 今までどおり 月着陸で おわる |
| 月からの 離陸 | 月面で エンジン → `dir: 'ascent'`。高さ `MOON_UP.TURN_H`（15）まで まっすぐ、上むきの 速さ `VR_MAX`（10）までで 高さ `HOLD`（150）を めざし、月の まわる 向きへ。加速は 月の重力の `ACC`（5）倍まで。近い ところが `PE_MIN`（50）より 上で 自動で とめる |
| ✂️ `separate()` | エンジンを とめている／月面で、上に 段が あれば 切りはなす（燃料が のこっていても）。自動の 切りはなしと 同じ 処理（`doSep`）。月面では その段は `leftStages` に のこる |
| 月面で おわる `endSurface()` | 🏁。今までの 月着陸と 同じ 結果 |
| 往還 | 月に 着陸 した あと 地球に 着陸 ＝ `done.returned` |
| 最大G | 重力を のぞいた 加速 ÷ 10（`sim.maxG`、`done.maxG`） |
| スローモーション | 「つぎの できごと」に `+home`（月から かえれる 線に なる）を 足した。なったら とめるまで ゆっくり |

## 3. 予測の線（js/predict.js）
- 月から はなれる とき、その 先を 地球から 見て えがく（`after`）。くうきに 入る なら **かえれる（home）**：色 `#00ffb0`・🏠
- 月に 着陸 した あと 地球の 重力圏で くうきに 入る 線も home
- `RL.Predict.homeFrom(st, t, bodies)`：月から見た 状態から かえれるか
- かえれる 線が 出たら 地図は 地球と 月が 両方 入る 大きさ

## 4. 画面（js/flight2d.js・index.html・css）
- 右の ボタンの 列の 左に もう1列（`#fctl2`）：✂️（3秒 以内に 2回。1回目で 黄色く 点滅して 声）、🚩（月面で 1回）
- 月面：🔥 が 光って 声で さそう。60秒 なにも しないと 1回 声（`MOON_IDLE_SEC`）。🏁 は 月面でも 出る
- 月面で いまの 段に 燃料が なく 上に 段が ある とき 🔥 → 「はさみで きりはなそう」
- ✂️ で のこした 段：月面の 間は そのまま 立っていて、離陸 した あとは 地面に かんたんな 着陸機の 絵（地面と いっしょに うごく）。🚩 も 同じ
- くうきに たいする 速さ ＞ `REENTRY.HOT`（150）で ロケットを つつむ 🔥 の 光と「あつい！」、🪂 の やぶれない 速さに なったら「いまだ！ パラシュートを ひらいて！」
- ⏪ を おぼえる 場所に 足した：月面（着陸・✂️・🔥 の 前）、地球の くうきの 手前（かえる とき）

## 6. しらべた 数字
`tools/return_check.js`（新）：landing_check の 自動パイロットで 月に 着陸 → 離陸 → 月を まわりながら 待つ 時間を かえて 前へ → 🏠 で とめる → くうきで ✂️ → 速さ 75 で 🪂

| 組み立て | 月面の Δv | 離陸 | かえる | 結果 |
|---|---|---|---|---|
| 見本 3段3列（15・18行で つくれる） | 151 | 99 | 40 | **往還 ↓2.8・🪂 高さ246・最大 15G** |
| 3段1列 B6 E4T｜V2T｜V脚2T（14） | 106 | 99 | — | 燃料ぎれ（かえれない） |

- 設計の 見つもり（月面→地球 130〜145）に たいし 実測 139。**見本でも のこりは 約12 しか ない**。月を まわる どこで 前へ ふかすかで かえれる／かえれないが かわる（ツールは 31回目で 成功）
- 離陸の 軌道は 近い ところ 52・遠い ところ 約1,900 の だ円に なる（月を まわる 軌道としては 正しい。かえる Δv は 円より 少ない）
- 18行で もっと 大きく 積んだ 組み方（B5〜6・タンク 多め）は 自動パイロットでは 月に 着陸 できなかった（重く なって 月で 止まりきれない／月と であう 待ち時間が 見つからない）。**18行に 余裕の ある 往還の 組み方が あるかは まだ わからない**
