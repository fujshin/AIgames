## 0. 乗組員だけで 大気に 入ると 着陸できる 件（バランスの 問題）

### しらべた 結果（v0.13 の 物理。近地点 150 で 月から かえる 軌道）

| かえってくる もの | 重さ | 地面での 下むきの 速さ | 今の はんてい |
|---|---|---|---|
| まど だけ | 0.22 | 6.6 | **着陸（あぶなかった）** |
| まど🪂（ひらかない） | 0.27 | 7.4 | **着陸（あぶなかった）** |
| まど＋さきっぽ | 0.33 | 11.0 | 衝突 |
| まど＋はね | 0.52 | 10.3 | 衝突 |
| タンク＋まど | 0.48 | 9.9 | 衝突 |

### 原因
- 空気の じゃまは **列の 数で きまり、重さに よらない**（`P.DRAG × 列の数`）。だから いちばん かるい まど 1こ だけが、いちばん ゆっくり おちる（おちる 速さは 重さの 平方根に 比例）
- 地球の 着陸の はんていは 下むき 5 まで 着陸、7.5（`HARD_K` 1.5 倍）まで「あぶなかった」。まど だけの 6.6 が この はばに 入っていた
- → **物理の まちがいでは なく、はんていの はばの バランスの 問題**

### 直し方（案）
地球の `LAND.earth.HARD_K` を **1.5 → 1.2**（あぶなかったの 上限 7.5 → 6.0）に する。

| 確かめ | 結果 |
|---|---|
| まど だけ／まど🪂（ひらかない） | 衝突に なる（6.6・7.4） |
| `earth_land_check`（🪂・エンジン・脚の 着陸） | v0.13 と まったく 同じ |
| `return_check`（見本の 往還） | 同じ（🪂 で ↓2.8） |
| 月の 着陸 | かわらない（地球だけ） |

- のこる 注意：まど だけの 6.6 と 上限 6.0 の 差は 小さい。空気の じゃまの きまりを かえる（重さで かえる など）方が しっかり するが、打ち上げの バランスにも ひびくので 今回は やらない
- ミッション 3-5（✂️ と 🪂）で 「🪂 が ないと かえれない」を 体験として おしえる

## 2. ミッションの しくみ

### 2-1. 画面
- タイトルに 🗺️ ボタン（ミッション）を 足す。こどもを えらんで いないと 押せない（今の ボタンと 同じ）
- ミッション地図：章ごとに 1列（左から 右へ すすむ すごろく）。1つ 1つは まるい カード
  - カードの 絵：おしえる もの（ボタンや 部品の アイコン）＋ ゴールの 絵（🛰️・🌙 など）
  - クリア した カードは ⭐ の 数、まだ ひらいて いない カードは 🔒
- 文字は 使わない。カードを 押すと 声で 「〇〇を してみよう」と 目的を いう

### 2-2. 1つの ミッションの ながれ
1. **はじめの 説明**（声＋絵。今の れんしゅうの `say`／`icon` と 同じ しくみ）
2. **準備**：
   - ロケット：「きまった ロケット（くみたて 画面を とばす）」「見本から 少し かえる」「じぶんで つくる」の どれか
   - 使える 部品：きめた ものだけ（れんしゅうの `allow` と 同じ）
   - はじまる 場所：地上／地球を まわる 軌道／月を まわる 軌道／月面／月から かえる とちゅう（3章）
3. **飛行中の あんない**：きめた できごとで 声と ボタンの 点滅（`hint`）
4. **クリアの はんてい**：条件が そろった しゅんかんに 🎉 → 結果画面に ミッションの ⭐
5. 失敗：今の 結果画面（⏪ も 使える）＋「もういちど」。3回 失敗したら 声で ヒントを 1つ 足す

### 2-3. ⭐ の きまり（どの ミッションも 同じ）
| ⭐ | 条件 |
|---|---|
| ⭐ | クリア |
| ⭐⭐ | ⏪ を 使わずに クリア |
| ⭐⭐⭐ | ミッションごとの 「もっと できたら」（燃料を のこす・ぴったり など） |

- つぎの ミッションは ⭐1 で ひらく

### 2-4. クリア条件の 書き方（実装の きまり）
ミッションごとに `goal` を 書く。下の 4種類を くみあわせる（ぜんぶ 今ある 値や できごとで はんていできる）：

| 種類 | 例 | 見る もの |
|---|---|---|
| `result` | 地球を まわる 軌道で 🏁 | `sim.done`（type・body・cls・chute・returned） |
| `event` | 月の 重力圏に 入った | `sim.events`（soi・class・stage-sep・surface・ascent-done など） |
| `state` | 近地点が 400 より 上で エンジンを とめた | その ときの `sim`（elements・fuelAll・dir など） |
| `ui` | 地図ボタンを 押した | ボタンの 押した 回数（ミッションの 間だけ 数える） |

```js
{ id: '2-3', icon: ['▼', '▲'], goal: [{ state: s => !s.isPowered() && s.cls === 'low' && peAlt(s) >= 400 && apAlt(s) >= 400 }],
  star3: s => peAlt(s) >= 800, rocket: 'orbitBasic', start: 'ground', allow: [] }
```

### 2-5. とちゅうから はじめる（新しく 要る しくみ）
- `RL.Orbit.create(a, { start })` を 広げて、空中（今ある）に 加えて 「軌道の 上（高さ・形）」「月を まわる」「月面」「月から かえる とちゅう」から はじめられるように する
- はじまりの 状態は ツール（`tools/mission_starts.js`）で 実際に 飛ばして つくり、`snapshot()` の 形で `js/missions.js` に しまう
- とちゅうから はじまる ミッションは カウントダウンを しない（声で 「いま 〇〇に いるよ」）
