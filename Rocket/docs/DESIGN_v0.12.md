## 2. 地球着陸（physics2d.js）
- `ORBIT.LAND` を 天体ごと（moon／earth）に。地球：下むき 5・よこ 3、地面ちかく 600、`MIN_ALT` 100 より たかく とんだ あとだけ
- 速さは 地面（まわっている）に たいして はかる（`relVel`）。ホバー・着陸の はんていも
- 地面ちかく（`sim.near`）：地球は「下に うごいていて、このまま だと 地面に つく（近地点が くうきの 中）」とき。まわって いる 間は 入らない
- 向きボタン：いちど エンジンを とめた あとは くうきの 中でも つかえる（打ち上げの 自動は そのまま）
- 地面ちかくの 画面：地球でも ロケットの 下はしを 地面に あわせる（月と 同じ）。着陸メーター・声・⏪ も 地球で うごく
- 空中から 始める：`RL.Orbit.create(a, { start: { h, vDown, vSide, fuel } })`（ミッション用。画面からは まだ よばない）

## 3. パラシュート
- 🪂 ボタン（パラシュートが ある ときだけ。出ていない 間も 場所は とっておく）。1回きり、1秒で ふくらむ
- くうきの 外：ひらかない（声）。くうきに たいする 速さ ＞ 80：**やぶれる**（声）
- 空気の じゃまに `CHUTE.CD`（2.2）× こ数 × ひらき具合 を たす。ひらいて いる 間は 真上を むいて ぶらさがる
- 月：くうきが ないので ひらかない（「エンジンで おりよう」）

設計の 数値（やぶれる速さ 40・2秒）では、くうきが うすい（300）ため 上から まっすぐ 落ちると いつも やぶれた。tools/earth_land_check.js で しらべて **80・1秒・CD 2.2** に した：

| 1200 から まっすぐ 落ちる | ひらく 高さ 250 | 150 | 80 | 30 |
|---|---|---|---|---|
| かるい（V+T） | やぶれ | やぶれ | 着陸 ↓3.1 | 着陸 ↓3.1 |
| おもい（E+3T） | やぶれ | やぶれ | やぶれ | 着陸 ↓4.4 |
| 軌道から もどる（150 で ひらく、速さ 45） | | 着陸 ↓3.1 | | |
→「まず 下で ゆっくりに なってから ひらく」が こたえ。おもい ロケットは ぎりぎりまで まつ か、パラシュートを ふやす。

エンジンで 地球に おりる（高さ 800・下むき 20 から）：地上用エンジンは できる。**宇宙用エンジンだけの 段は くうきの 中で 力が 30% なので 重いと とまれない**（今までの きまりどおり。パラシュートの 出番）。

## 4. 組み立て画面の スクロール（うちゅうモード）
- うちゅうモードは 縦 14 行（`ROWS_ORBIT`）、たかさモード・れんしゅうは 9 行（`ROWS_FREE`）。見えるのは 9 行（`VIS_ROWS`）、マスの 大きさは 今と 同じ
- ▲▼ ボタン（3行ずつ）・指で スワイプ。部品を おくと その 列の 上が 見える ように 自動で うごく
- 左の はしご → ロケット全体の 小さな 絵と 見ている わく（おすと そこへ うごく）
- 組み立ては モードごとに しまう（`p.grid`＝9行、`p.gridOrbit`＝14行。はじめは 9行の ものを 下に つめて つかう）
- 見本の ロケット（版表示 3回タップ）：うちゅうモードは B6・E4T｜V脚3T・まど🪂（月に 着陸 できる ことを 確かめた）

## 5. スローモーションの 作り直し（「急に 速く なる」の 修正）
- つぎの できごと（軌道の 種類が かわる／月と であう 予測に なる）まで あと 何の 速さが 要るかを はかり（`nextEventDv`、0〜200 を 二分法）、それが 実時間 3秒で くるように する
- いちばん おそくて 実時間1秒に 1.5（`DV_MIN`）。月と であう 予測が 出たら とめるまで その まま
- 燃やしている 間は 早送りを 上げる はやさも ゆっくり（1こま 1.02倍）
- `tools/slow_check.js`（見本・低い軌道から 125秒後）：再点火 → 月と であう 予測まで 実時間 **20.5秒**（v0.11.1 は 56.6秒、途中で 急に 7倍）。1こまで ふえる「1秒に ふえる速さ」の 最大 0.73（なめらか）
- flight2d の `sim.moonNear` は つかわなく なった（`RL.Predict.moonNear` は のこして ある）
