# v0.14.1：ミッションの あんないを ていねいに（1章を つくりなおし）

## 1. あんないの しくみ（`steps`）
ミッションごとに **じゅんばんに すすむ あんない** を もつ。1つの あんないは「声」と「光らせる もの」。つぎの あんないに すすむまで **ずっと 光る**（金色の わく＋ぱたぱた）。

| 項目 | 意味 |
|---|---|
| `at` | どこで すすむか：`build`（くみたて）／`fly`（飛行中）／`result`（結果） |
| `when` | すすむ 条件（なければ すぐ） |
| `hl` | 光らせる もの：ボタンの id、`pal:tank`（パレットの 部品）、`cells:'top'`（ロケットの いちばん うえの マス） |
| `need` | この 打ち上げかたで ないと 発射 しない（声で おしえて 打ち上げかたの ボタンを 光らせる） |
| `block` | この あんないの 間は 発射 しない（あんないを もういちど いう） |
| `fail` | **わざと しっぱい** する 結果。しっぱいに かぞえず、結果画面は 💡 と せつめいの 声 |
| `rew` | わざと しっぱい の 結果で ⏪ を 出す |

- ミッションの はじめに **めあての 大きな 絵**（タップか 2秒で とじる）→ さいしょの あんない
- 上の ミッションの しるし（🔊 1-1 …）を おすと、いまの あんないを もういちど 声で いう
- しっぱい（あんないに ない）したら、その 飛行の はじめの あんないに もどる
- 1章は 「じめんが ちかいよ」「あつい！」など ふだんの 声を ださない（`quiet`。あんないと ちがう ことを いわない）
- 2・3章は いままでの はじめの 声＋ヒントを じゅんばんの あんないに した（光る ものが のこる）。3-1 は パラシュートを つけたら 発射ボタンが 光る
- ⏪：うちゅうに でた ところも おぼえる（ほかに おぼえる ところが ない 飛行でも もどれる）
