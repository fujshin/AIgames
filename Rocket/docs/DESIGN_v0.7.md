# Rocket Lab v0.7 設計：2段式と宇宙用エンジン

## ねらい
「とにかく積む」から「段ごとに役わりを考える」へ。**下の段＝地上用で力強く、上の段＝宇宙用で遠くまで** に、子どもが自分で行き着けるようにする。

## 追加した部品
| 部品 | はたらき | 数値 |
|---|---|---|
| 切りはなしリング | リングより下の行が1段目、上が2段目（リングの行は下の段）。いまの段で燃えるものがなくなると リングごと外れ、0.3秒後に次の段が点火 | 重さ 0.3 |
| 宇宙用エンジン | くうきの中では力 30%、くうきの外で本来の力。燃料がながもち | 力 120／重さ 0.6／燃料の使い方 0.45 |

地上用エンジン：力 188／重さ 1／燃料の使い方 0.93（v0.6.3 と同じ）

## 組み立て画面
- 横5 × 縦9。リングがあると、段ごとに背景の色が変わる（1段目オレンジ、2段目水色…）
- ブースターは胴体のすぐ となりにだけ置ける（となりに胴体がないと ブー音＋となりの胴体が光る）。胴体より高くはみ出した分は半とうめいになり、ロケットに含まれない

## 飛行中
- 段の切りはなし：音・画面の光・「だいいちだん、きりはなし！」。外れた段はまっすぐ下へ落ちる
- 次の段の点火：「にだんめ、てんか！」
- 宇宙用エンジンの青いほのおは、くうきの中では小さく、宇宙で大きくなる。オレンジの力の矢印も同じように伸びる

## チュートリアル 第6章
1. リングを紹介 → 地上用＋燃料3 の上にリング
2. 2段目に地上用エンジン＋燃料2 → 発射（段が外れるのを見る）
3. 宇宙用エンジンを紹介 → 2段目を宇宙用＋燃料2 に作り直して発射（さっきよりずっと高い）
4. 逆（下が宇宙用）を発射 → 1段目は動けない
5. 「したは ちからもち、うえは ながもち」。ブースター＋宇宙用の段で どせいへ、のヒントで自由モードへ

## 決めたこと
- 縦9マスで、長いブースター4本＋宇宙用エンジンの1段が15,000を超えた → ブースターは胴体のとなり・胴体の高さまで、のきまりにした
- 2段目のはね：くうきの中で効く（宇宙では おもり）
- 低い高さで切りはなして宇宙用エンジンが弱いとき：地面でふんばり、軽くなったら とぶ
- 土星の先の目標は置かない（v0.8以降で検討）
