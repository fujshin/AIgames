# v0.20.0：⛽ ねんりょう ステーション（地球を まわる 軌道での 補給）
設計（DESIGN_v0.20_refuel）の「決めて ほしい こと」は 案の とおり（はじめから 1つ／燃料は かぎり なし／自動で キャッチ／のこっている 段を ぜんぶ 満タン／部品は いらない）。
高さだけ 実装で かえた（600 → **3000**。下の「わかった こと」）。v0.20.0 は じゆうに あそぶ（うちゅうモード）で つかえる ところまで。7章は v0.20.1〜。

## あそびかた
1. 地球を まわったら エンジンを とめる → 地図に ⛽ へ いく ひかる しるし（🔥）
2. しるしで まえへ ふかす。予測の 線の 上に うすい ⛽ と きょり（↔）。みどりに なったら とめる
3. ⛽ に ちかづくと 上に メーター（↔ きょり・🚀 くらべた はやさ）と 声「ステーションに ちかづいたよ！ うしろむきで ほのおの ボタンを つけた まま…」
4. うしろむきの 🔥 で 自動で ⛽ に あわせて ちかづく → アームで キャッチ（ドッキング）
5. ⛽ ボタンで 満タン → 🔥 で はなれる（勲章 ⛽）

## わかった こと（高さ 600 → 3000）
- 打ち上げて とめた 軌道の ▲ は ロケットで 700〜2900。600 だと ▲ が もう ⛽ より 上で、しるしが でない
- 600 は 低い軌道との まわる はやさの 差が 小さく、つぎに であえるまで ゲームで 約9,700秒（実時間 7分）。3000 は 約900秒
- ▲ で あった ときの くらべた はやさは 20〜50。子どもが あわせるのは むずかしい ので「うしろむきの 🔥＝⛽ に あわせる」に した

# v0.20.1：アスパラガスの 手直し・列ごとの ⛽ メーター・6-2 の 下の 段

| なおした こと | 原因／中身 |
|---|---|
| よこの 列が 段の さかいめを またぐと、上の タンクだけ ちぎれて 上の 段に のこる | v0.17.1 の「段ごとに わける」が、上の かけらに エンジンが なくても わけていた。タンクだけの かけらは よこの 段に ならず、上の 段の ふつうの 部品に なって、よこの 段が はずれた あとも 横に うかび、宇宙用エンジンの 燃料に なっていた。**上の かけらの いちばん 下が エンジンの ときだけ わける**（physics.js） |
| 「そとだけ せん」で うちの 列が さきに はずれる | うちの 列は まんなか・うち左右の 3つの エンジンに すわれて、そとの 列（せんで じぶんだけ）より さきに からに なっていた。**同じ がわの そとに よこの 段が のこっている 間は、うちの 列は からでも はずれない**（`held`）。その 間 うちの エンジンは まんなかの 燃料で もえる（physics2d.js） |
| ⛽ メーターに よこの 段の 燃料が 出ない | よこの 段が ある 間は **列ごとの メーター**（ロケットの 列の ならび）。まんなか＝いままでの ⛽、よこ＝その 列。すわれている 列は まんなかへ ▶、せんの 列は 赤い まる、はずれた 列は はいいろ ✕（flight2d.js `podCols`・`drawPodFuel`）。`fuelRatio()` は かえていない（ミッションの ⭐ は そのまま） |
| 6-2：切りはなした はずの 下の 段が 見える | とちゅうから はじまる ミッションで、はじめから ない 段の 見た目を けしていなかった（⏪ の ときだけ `syncParts`）。start の ときも よぶ |
