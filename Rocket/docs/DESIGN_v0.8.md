## 世界の大きさ（縮小縮尺）
| 値 | 設定 | 理由 |
|---|---|---|
| 地球の半径 R | 12,000 | 第1宇宙速度 √(10×12000) ≒ **346**。今の部品のΔv（264〜約680）で「2段式でぎりぎり周回、ブースターつきで月・脱出」になる大きさ |
| 第2宇宙速度 | ≒ 490（= 第1 × √2） | 縮小しても √2 の関係はそのまま |
| くうき | 300（半径の2.5%。ほんもの 1.6%） | たかさモードと同じ |
| 自転 | 地面の速さ = 第1宇宙速度の 6% | ほんものと同じ割合。真上に打っても少し横に流れる |
| 月 | 距離 15R、半径 0.27R、重さ 1/81、重力圏 ≒ 2.6R | 半径・重さは ほんものの比 |
| 地球の重力圏 | 30R | ここを出たら「地球だっしゅつ」 |
| 低軌道 1周 | 約218秒 | 早送りで 約10秒 |

## 計算のしくみ（パッチドコニック）
- 位置・速度は「いま いる重力圏の天体」から見た値。重力は その天体だけ
- エンジンを使っている間・くうきの中：0.02秒きざみの数値積分（空気のじゃまは 地面といっしょに回る空気に対して）
- 惰性で うちゅうを飛ぶ間：**ケプラー軌道の式（レール上）**。早送りしても軌道がくずれない。くうき・地面・重力圏の境目は 二分法で ちょうどの瞬間を さがす
- ほぼ真上に打った 細長すぎる軌道は 式が不安定なので、重力だけの RK4（きざみ自動）にまかせる
- 打ち上げた衛星を将来ためるときは、軌道要素（a, e, w, s, tp）を保存するだけで いつでも位置が出せる

## 打ち上げ方（自動でかたむける）
組み立て画面の 新しいボタンで切りかえ（うちゅうモードのときだけ出る）。
| 絵 | 名前 | 動き |
|---|---|---|
| ⬆ | まっすぐ | ずっと真上。速ければ 遠くまで行って もどる／にげる（第2宇宙速度の体験） |
| ↗ | ななめ | 高さ220までに 45°へ |
| ➡ | よこ（はじめの設定） | くうきの中は 上むきの速さ50を保ちつつ たおす。くうきの外では 高さ約390を保ちながら 横に加速（力が弱いほど 上むきに） |

はね・左右のバランスによる「かたむき」は v0.7 と同じきまりで、自動の角度に足される。

## 飛行中の画面
- **ちかく**（くうきの中）：空・雲・地面。東＝左（地図と同じ向き）。左上に小さな地図
- **地図**（くうきの外で自動で切りかえ／ボタンでも）：地球・月・月の通り道・とんできたあと・**予測の線**
  - オレンジ＝地面にぶつかる（弾道） ／ みどり＝まわりつづける（周回） ／ むらさき＝にげる（脱出）
  - ▼近地点 ▲遠地点 の高さ
- **速さメーター**：🛰️1（第1宇宙速度）と 🚀2（第2宇宙速度）の しるし。いまの高さでの値なので、高いほど左へ動く
- ボタン（右下）：🔥エンジン 止める／つける（液体だけ。ブースターは止められない）、🗺 地図／ちかく、🏁 おわる（安定した軌道のとき）
- ✋中止（左上・0.9秒 長おし）：結果を出さず、組み立てたまま もどる。たかさモードでも使える。チュートリアル中は出さない

## バランス（tools/orbit_v0.8.txt）
- 1段は どの構成でも周回できない（Δv 最大 約430）
- 2段「地上用→宇宙用」（E3T｜V2T、Δv 566）：よこ で ちょうどよく止めると 低い軌道（燃料 残り2%）
- ブースターつき2段：周回して燃料が 約10%のこる → 月・脱出をねらえる
- 低い軌道から再点火のタイミングを変えると、月の重力圏に入る／月にぶつかる／**月の近くを通って 脱出（スイングバイ）** が自然に起きる（tools/moon_test.js）
- 地図で「線が地球をひとまわりした」から 燃料が切れるまでの時間は、上の2段式で 約2秒 → 13歳向けのむずかしさ。5歳は 🏁 が出なくても 落ちる／にげる を楽しめる

## v0.8.1（改修3：軌道の判定・地図・予測の線）
### 直したこと
- 切りはなしの あと、ロケットが 画面の はしに よったままになる → **のこっている部分の まんなか** を中心に かたむけ、画面の まんなかへ なめらかに うごかす（うちゅうモード・たかさモードの 両方。js/flight.js の rocketCam / remainBox）。けむりの出る位置・力の矢印も のこっている部分に あわせた

### 予測の線（js/predict.js）
- いまの重力圏の軌道を たどって、**地面にぶつかる／重力圏を出る／月の重力圏に入る（であい）** を さがす
- 月と であうなら、月から見た軌道に のりかえて 続きを描く。中心は **であう ときの 月の位置（うすい月）**
  - 月に ぶつかる 💥 ／ 月を まわる ／ 月の そばを 通りぬける（そのあと 🚀にげる・🔄地球にもどる・💥おちる の しるし）
  - 月に いちばん ちかづく ところの 高さ ▼
- 線の色：オレンジ＝おちる、みどり＝まわる、むらさき＝にげる、水色＝月の まわり
- 画面の上に「このまま とぶと どうなるか」の しるし：💥 ／ 🛰️ ／ 🚀 ／ 🌙➡️ ／ 🌙🛰️ ／ 🌙💥
- 月と であう線に かわった しゅんかん「つきに とどく きどうだ！」
- 計算は physics2d と同じ式・同じ天体。燃えている間は 毎こま、惰性の間は 0.1秒ごとに 計算しなおす
- 月に ちかづくと 早送りを ゆるめる（であいを 見のがさない・見せる）
