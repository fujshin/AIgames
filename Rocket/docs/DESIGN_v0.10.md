# Rocket Lab v0.10 設計：向きボタン（前へ／うしろへ）と 月を まわる

v0.9.1 の上に足す。打ち上げ（くうきの中・自動の かたむけ方）は かえていない。

## できること
| 項目 | 内容 |
|---|---|
| 向きボタン | 飛行中の 右下（🔥の すぐ下）。おすたびに **前へ ⇄ うしろへ（ブレーキ）**。くうきの外で、液体燃料が あるときだけ 出る（出ていない間も 場所は とっておく） |
| 前へ | すすむ向き（いま いる 天体から 見た 速さの 向き）へ まっすぐ おす |
| うしろへ | すすむ向きの 反対へ おす＝ブレーキ。月の重力圏で つかうと 月を まわれる |
| 自動 → 前へ | 打ち上げは 今までどおり 自動。うちゅうで いちど エンジンを とめたら、つぎからは「前へ」 |
| 見た目 | ロケットは 1秒に 4ラジアン（約230°）で くるっと まわる（向きの 計算は すぐ かわる。見た目だけ なめらか） |

| 月の重力圏に 入った（燃料あり） | 「…つきに いちばん ちかづいたら、うしろむきに ふかすと、つきを まわれるよ。」 |
| 月に いちばん ちかづく すこし前 | 「いまだ！ うしろむきに して、エンジン！」（向きボタンと 🔥が ひかる） |

## しくみ
- `physics2d.js`：`sim.dir`（'auto' / 'pro' / 'retro'）、`setDir()`、`canDir()`、`aimAngle()`。くうきの外で dir が auto 以外なら、おす向き ＝ 速さの 向き（retro は 反対）
- 月を まわる の はんてい（`clsOf`）：月に ぶつからず、**月の重力圏の 中に おさまる** だ円（はみだすなら 通りぬけ）。予測の線（predict.js）と 同じ きまり
- スローモーション（`ORBIT.SLOW`）：月と であう 予測に かわる すぐ手前（あと `LOOK_MOON`=10 足すと であう）は 1秒に ふえる速さ `DV_MOON`=0.2 まで ゆっくり（とめる タイミングが 2秒くらい ある）。月の重力圏では 早送りを ひかえめに
- 予測：`RL.Predict.moonNear()`（新規）

## 確かめ
- tools/capture_check.js（新規）：低い軌道 → wait 秒後 前へ → 月と であう 予測で とめる →「いまだ」で うしろへ → 月を まわったら とめる
  - B5 E3T｜V3T：wait 2秒・20秒で 月を まわる（燃料 4% → 1〜2%）。40・60秒は 月と であわない（打つ タイミング しだい）
  - B9 E3T｜V3T、B9 E2T｜V5T：wait 2秒で 月を まわる
  - 月の重力圏に 入って すぐ うしろへ ふかすと、月に おちる（はやく ブレーキ しすぎ）
- tools/predict_test.js：予測の線と 実際 46/46 一致
- 打ち上げ（tools/orbit_check.js）：結果は v0.9.1 と 同じ
- ブラウザ（ヘッドレス Chromium）：打ち上げ → 低い軌道 → 前へ → 月と であう → 「いまだ」→ うしろへ → 月を まわる → 🏁 → 結果 🌙⭐5・勲章 🌕・月を まわる 衛星が ワールドに のこる。エラーなし
