# Rocket Lab v0.11：月着陸 と ここからやり直し（実装の 記録）

v0.9.1 の バンドルに v0.10（向きボタン）と v0.11 を 入れた。設計の 「決めて ほしい こと」は すべて 案の とおり。

## 1. 月着陸
| 項目 | 内容 | 設定（config.js `ORBIT.LAND`） |
|---|---|---|
| 着陸 | 月の 地面に ふれた ときの 下むき ≤ 4、よこ ≤ 3 | `V_DOWN` `V_SIDE` |
| あぶなかった | 上の 1.5倍まで（星 −1）。真上から 35°（脚 左右で 50°）より たおれて いても こちら | `HARD_K` `TILT_MAX(_LEG)` |
| 衝突 | それより 速い（今までどおり 🚩） | |
| 地面ちかく | 高さ < 2,000。ちかくの画面（灰色の 地面・クレーター・地球）・着陸メーター・脚が ひらく | `NEAR` |
| ちょろちょろ噴射 | 地面ちかくでは エンジンを 月の重力の 3倍まで 自動で しぼる | `TWR` |
| ホバー | 「うしろへ」で 速さ < 1.5 に なったら 真上に むいて 浮く。エンジンを とめると おちる | `V_HOVER` `HOVER_GAIN` |
| スロー | 地面に つくまで 実時間で 6秒より みじかく ならない | `SLOW_SEC` |

着陸メーター（燃料メーターの となり）の ▶ は「いま エンジンを とめたら 地面に つく 速さ」。みどりの ときに とめれば 着陸できる。
着陸脚（パレット 9こめ）：胴体の となり。さいごの 段 以外は 半とうめい。ゆるされる 速さが 2.5倍。飛行中は たたんで 月の 地面ちかくで ひらく。

## 2. 燃料の バランス
いまの 数値の ままでは 月に ついた ときの のこりの Δv が 最大 約40 で 着陸（約150）が できない。
**うちゅうモード だけ、宇宙用エンジンの くうきの外での 燃料の へりを 0.7倍**（`ORBIT.VAC_VBURN_K`）。たかさモードは かわらない。

| 構成（tools/landing_check.js、自動の パイロット） | 月に ついた ときの Δv | 結果 |
|---|---|---|
| 見本：2段 B5 E3T｜V2T＋さきっぽ＋着陸脚 | 237 | 着陸 |
| 2段 B5 E3T｜V3T（v0.10の見本、脚なし） | 296 | 着陸 |
| 2段 B4 E2T｜V3T＋脚 | 216 | 着陸（のこり わずか） |
| 2段 E3T｜V2T（ブースターなし） | 80 | 衝突（燃料が たりない） |

# v0.11.1：手直し（3点）

| なおした こと | 原因 | なおし方 |
|---|---|---|
| 月の 地面に つく 前に 爆発する | 月の ちかくの画面で、地面の 位置を 打ち上げ時の ロケット（9マスぶん）の 下はしで きめていた。切りはなした あとの ロケットは 短いので、地面との 間に すきまが できて いた | ロケットの のこっている 部分の 下はしから「高さ」ぶん 下に 地面を かく（高さ 0 で ぴったり）。💥 も 地面の ところに 出し、ロケットは けす |
| ⏪ で もどると すぐ 爆発する | 🔥を つける たびに おぼえて いたので、地面の すぐ 上で 🔥を おすと「もう まにあわない ところ」を おぼえて いた | 月の 地面ちかくでは「いまから エンジンで とまれる」（とまる きょり < 高さ×0.6、高さ > 60、燃料あり）ときだけ おぼえる。まにあわない ときは ひとつ 前の（地面ちかくに 入った ときの）場所に もどる |
| 燃料メーターの さいごが 見えない | ロケット ぜんぶの 燃料に 対する 割合だった | **切りはなしの たびに その ときの のこりを 100%**（`sim.fuelBase`）。満タンに もどる ときに ぴかっ と ひかる。メーターの 下に のこりの 段の 数を ●（いまの 段は 黄色）。たかさモードも 同じ |

確かめ（ヘッドレス Chromium）：見本で 着陸 → ロケットの 足が 地面に ぴったり。わざと 地面すれすれで 🔥を おして 衝突 → 結果の ⏪ で 高さ 約1,940（地面ちかくに 入った ところ）に もどる → 3秒 なにも しなくても ぶつからない → 着陸 ⭐4。燃料メーターは 切りはなしで 100% に もどる。landing_check・predict_test（46/46）・balance_check は v0.11 と 同じ。エラーなし。
※ ツール用の 割合（ロケット ぜんぶに 対する）は `sim.fuelAll()`。
