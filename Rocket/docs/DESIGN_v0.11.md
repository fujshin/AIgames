# Rocket Lab v0.11：月着陸 と ここからやり直し（実装の 記録）

v0.9.1 の バンドルに v0.10（向きボタン）と v0.11 を 入れた。設計の 「決めて ほしい こと」は すべて 案の とおり。

## 1. 月着陸
| 項目 | 内容 | 設定（config.js `ORBIT.LAND`） |
|---|---|---|
| 着陸 | 月の 地面に ふれた ときの 下むき ≤ 4、よこ ≤ 3 | `V_DOWN` `V_SIDE` |
| あぶなかった | 上の 1.5倍まで（星 −1）。真上から 35°（脚 左右で 50°）より たおれて いても こちら | `HARD_K` `TILT_MAX(_LEG)` |
| 衝突 | それより 速い（今までどおり 🚩） | |
| 地面ちかく | 高さ < 2,000。ちかくの画面（灰色の 地面・クレーター・地球）・着陸メーター・脚が ひらく | `NEAR` |
| ちょろちょろ噴射 | 地面ちかくでは エンジンを 月の重力の 3倍まで 自動で しぼる（ほのおも 小さく、燃料も ながもち） | `TWR` |
| ホバー | 「うしろへ」で 速さ < 1.5 に なったら 真上に むいて 浮く。エンジンを とめると おちる | `V_HOVER` `HOVER_GAIN` |
| スロー | 地面に つくまで 実時間で 6秒より みじかく ならない | `SLOW_SEC` |

設計では「真上に 固定」だったが、そのままだと 上に のぼって いって しまうので **ホバー（その 高さで 浮く）** に した。
あそびかた：うしろむきで ブレーキ → 浮いたら エンジンを とめて おちる → また ブレーキ … を くりかえして ひくく する。
**着陸メーター**（燃料メーターの となり）の ▶ は「いま エンジンを とめたら 地面に つく 速さ」。みどりの ときに とめれば 着陸できる。

### 着陸脚（新しい 部品・パレット 9こめ）
- 胴体の となりに つく（はねと 同じ）。つかないと 半とうめい。さいごの 段 以外に ついた 脚も 半とうめい（切りはなしで すてられる）
- ゆるされる 速さが 2.5倍（`LEG_K`）。おもさ 0.06。空気の じゃまは なし
- 飛行中は たたんで いて、月の 地面ちかくで ひらく（音つき）

### 声
月の重力圏で ブレーキの おしえ → 「いまだ！」 → 「じめんが ちかいよ！」 → 「はやすぎる！ エンジン！」（とまりきれない とき） → 「ういてるよ！ …みどりの ときに とめると…」 → 着陸の ファンファーレ。

## 2. 燃料の バランス（だいじ）
いまの 数値の ままでは、マス目に 入る どの ロケットでも 月に ついた ときの のこりの Δv が 最大 約40 で、着陸（約150 要る）は できなかった。
**うちゅうモード だけ、宇宙用エンジンの くうきの外での 燃料の へりを 0.7倍**（`ORBIT.VAC_VBURN_K`）に した。たかさモードは かわらない。

| 構成（tools/landing_check.js、自動の パイロット） | 月に ついた ときの Δv | 結果 |
|---|---|---|
| 見本：2段 B5 E3T｜V2T＋さきっぽ＋着陸脚 | 237 | 着陸（↓4.2〜4.7、脚で OK） |
| 2段 B5 E3T｜V3T（v0.10の見本、脚なし） | 296 | 着陸（↓2.8） |
| 2段 B4 E2T｜V3T＋脚 | 216 | 着陸（のこり わずか） |
| 2段 E3T｜V2T（ブースターなし） | 80 | 衝突（燃料が たりない） |

パイロットは ほぼ むだなく 飛ぶので、子どもには 見本くらいの 大きさが 要る。
**かわった こと**：うちゅうモードの 打ち上げ・地球まわりも 少し 楽に なる（例：2段 E3T｜V2T は 低い軌道で 燃料 2% → 7% のこる。まっすぐ うつと 地球を にげられる）。予測の線と 実際は 46/46 一致のまま。
