# Rocket Lab v0.8.3 設計：上の しるしを やめる・ボタンの位置・おわり方

## 1. 上の まんなかの しるし（💥🛰️🚀🌙➡️…）を やめた
「いま エンジンを 止めたら どうなるか」を 出していた。打ち上げ中は ほぼ いつも 💥（止めたら 落ちる）なので、意味が わかりにくかった。
同じことは 予測の線の 色（オレンジ＝おちる／みどり＝まわる／むらさき＝にげる／水色＝月の まわり）と 声（「つきに とどく きどうだ！」）で わかるので、しるしは 消した。

## 2. ボタンの位置を かえない
🏁（おわる）が 出たり 消えたり するとき、display を 切りかえていたので、右下の ボタンの列の 高さが かわり、🔥（エンジン）と 🗺 が 上下に うごいていた。
v0.8.3 から 🏁 は visibility で 出し入れする（出ていない間も 場所は とっておく）。🔥 と 🗺 は いつも 同じ位置。

## 3. おわり方（安定した軌道のとき）
v0.8.2 までは「安定した軌道を 1.2周 まわったら おわる」だった。月まで とどく軌道は 1周が 長く（約4,500〜7,000）、月と であう前に おわっていた（tools/wait_check.js で 4通りとも 月と であう前に おわった）。

| じょうけん | おわる まで | 設定 |
|---|---|---|
| 液体燃料が のこっている | 🏁を おすまで（エンジンを 使わず 12周 まわったら おしまい） | `ORBIT.IDLE_TURNS` |
| 燃料が ない・ひくい／たかい軌道・月を まわる | 1.2周 | `ORBIT.ORBIT_DONE` |
| 燃料が ない・月まで とどく軌道 | 4周（月と であうのを まつ） | `ORBIT.MOON_WAIT` |

地面に おちる／月に ぶつかる／地球の重力圏を 出る は 今までどおり すぐ おわる。月の重力圏に 入ると 周回の数えは 0 に もどる。
ツール用の runToEnd は 今までどおり 1.2周で おわる（`autoEnd`）ので、orbit_check の 結果は かわらない。

### 確かめ（tools/wait_check.js）
低い軌道 → 再点火して「月まで とどく軌道」に なったら 止めて まつ（燃料 約4% のこり）。
| 再点火 | v0.8.2 | v0.8.3 |
|---|---|---|
| 10秒後 | 1.2周で おわり | 月と であって 通りぬけ |
| 40秒後 | 1.2周で おわり | 月と であって 地球へ もどる |
| 80秒後 | 1.2周で おわり | 月と であって また まわる（🏁 か 12周で おわり） |
| 120秒後 | 1.2周で おわり | 月と であって 通りぬけ |
予測の線と 実際の一致：46/46。月まで とどく軌道 1周は 実時間で 約16秒（早送り込み）。
