## しくみ（js/save.js）
- localStorage の `rocketlab.save.v1` に JSON で しまう。つかえない ブラウザでは 画面を とじるまで だけ おぼえる。こわれた データは 白紙から
- 衛星は 軌道要素（mu, a, e, w, s, p, n, tp …）を しまう。どの 時刻でも 位置が 出せる（レール上）
- ワールドの 時計：うちゅうモードで 飛んだ 時間（中止も ふくむ）だけ すすむ。衛星の 時刻 ＝ しまった ときの 時刻 ＋（いまの ワールド時刻 − しまった ときの ワールド時刻）
- 月の 位置は いままでどおり 毎回 同じ ところから はじまる（月を まわる 衛星は 月と いっしょに うごく）
- 衛星・はた は 24こ まで（`SAVE.MAX_OBJS`）。こえたら ふるい ものから けす
- れんしゅう中の 組み立て・きろくは しまわない（れんしゅうが おわったら 自分の ロケットに もどる）。勲章は れんしゅう中でも もらえる

## 設定（config.js `SAVE`）
`KEY`、`SLOTS`（4）、`AVATARS`、`MAX_OBJS`（24）、`FLEET`（3）

## 確かめたこと（ヘッドレス Chromium）
はじめて ひらく → どうぶつ えらぶ → うちゅうモードで 高い軌道 → 衛星1こ・勲章 🌌🛰️📡 → 再読みこみで こども・ロケット・勲章が もどる → 2回目の 地図に 衛星 → 中止 → 2回 確認して けす → えらぶ 画面に もどる。こわれた データ、れんしゅう完了の 🎓、同じ どうぶつを えらべない ことも 確認。エラーなし。
