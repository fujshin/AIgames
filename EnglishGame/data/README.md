# data/ フォルダ（作業の引きつぎ用）
- `words_j1.csv` `words_j2.csv` `words_j3.csv`：ゲームに 入っている 単語データの 元表（Excel で 開けます。訳の 確認にも 使えます）
- `a2_candidates.csv`：CEFR-J の A2 語彙（中1と 重なる語を のぞき、NGSL の 頻度順）。中2・中3 の 候補
- `b1_candidates.csv`：CEFR-J の B1 語彙（NGSL の 頻度順）。中3 後半〜高校 の 候補

## 単語の 選びかた
- 中1：CEFR-J A1（ただし 代名詞・前置詞など 機能語は のぞく）
- 中2：A2 の よく使う語（NGSL 頻度順）
- 中3：A2 の のこり（学習用に 選んだ もの）＋ B1 の 頻度の高い語（後半で 追加）
作業環境が リセットされたときは、このフォルダごと アップロードすれば 続きから 作業できます。
- `words_h1.csv`：高1（B1 語彙のうち NGSL で 頻度の高い語）
- `words_h2.csv`：高2（B1 語彙のうち 入試・論説文に よく出る語）
- `words_h3.csv`：高3（CEFR-J B2 語彙のうち NGSL で 頻度の高い語）
- `b2_candidates.csv`：CEFR-J の B2 語彙（NGSL の 頻度順）。高3 の 候補
