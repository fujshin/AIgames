# えいたんクエスト（英単語RPG） v1.7.0

中1〜高3の 学年別 英単語を、RPGの バトルで おぼえる ゲームです。
サーバー不要。GitHub Pages に そのまま 置くだけで 動きます（セーブは ブラウザの localStorage）。

中学は 学年別（中1・中2・中3）、高校は 難易度別（基礎・標準・発展）の 6つの 地方、計3,663語。

## レベル診断
- マップ下の「🔮 レベル診断」（はじめて遊ぶときにも すすめます）
- 中1・中2・中3・高校基礎・標準・発展 から 6問ずつ、最大36問。「わからない」を えらべます
- 続けて 2つの レベルで ほとんど わからなければ 早めに 終わります
- けっかで おすすめの 地方と 章が 出て、そこまでの 章は 最初から ひらきます

## 高校の 3レベル（難易度順）
高校の 1,856語を、CEFR-J のレベル・NGSL の頻度・抽象語の語尾（-tion, -ity など）・語の長さ・身近な名詞か で 点数をつけ、やさしい順に 3等分しています。
| レベル | 目安 |
|---|---|
| 高校 基礎（h1） | 共通テストの 土台 |
| 高校 標準（h2） | 共通テスト〜中堅大 |
| 高校 発展（h3） | 難関大 |
ファイル名（words_h1.js など）は そのままです。

## 公開のしかた（GitHub Pages）
1. このフォルダの中身を リポジトリの ルートに アップロード（`index.html` が いちばん上）
2. **Settings → Pages → Branch: main / (root)** で Save

## 更新するときの キャッシュ対策
`index.html` の `app-version` と `?v=`、`js/game.js` の `APP_VERSION` を 同じ番号に 上げてください。

## ファイル構成
```
index.html           画面の骨組み
css/style.css        見た目
js/config.js         学年・地方・モンスターの設定
js/words_j1.js〜     学年ごとの 単語データ
js/game.js           ゲーム本体
data/                単語データの 元表（CSV）。作業の 引きつぎ用
assets/              イラスト（なくても 絵文字で 動きます）
```

## 学年を ふやすとき
1. `js/words_h1.js` を `WORDS.h1 = [ ... ];` の形で 作る
2. `index.html` に `<script src="js/words_h1.js?v=..."></script>` を 1行 追加

単語データの1行：`["英単語", "品詞(n/v/a/d)", "意味（／で併記）", "型", "例文（[ ]が空欄）", "例文の訳"]`

## セーブデータについて
学年の 最初の30語が かわると、その学年の「ステージ クリア記録」だけ リセットされます（単語ごとの 記録は のこります）。末尾に 単語を ふやしただけなら リセットされません。
